# QRコードスキャナー - ドラッグストアアプリ

jsQRを使用したQRコード読み込みアプリです。ドラッグストアでの商品管理や情報取得に活用できます。

## ✨ 機能

- 📱 **リアルタイムQRコード認識**: カメラからリアルタイムでQRコードを読み込み
- 🔗 **URL自動認識**: URLの場合は自動的にリンク化
- 📋 **ワンクリックコピー**: 読み込んだ内容をクリップボードにコピー
- 🔓 **オープン機能**: URLの場合はボタンで直接リンクを開く
- 📱 **モバイル対応**: スマートフォン・タブレット・PCで動作
- 🚀 **高速・軽量**: クライアント処理のみで外部サーバー不要

## 🛠 使用技術

- HTML5
- CSS3
- JavaScript (Vanilla)
- [jsQR](https://github.com/codegooglecom/jsQR) - QRコード読み込みライブラリ

## 📋 必要な環境

- HTTPS対応のブラウザ（カメラアクセスのため）
- Webカメラまたはスマートフォンのカメラ
- 最新のブラウザ（Chrome, Firefox, Safari, Edgeなど）

> **注**: HTTPSが必要です。LocalhostはHTTPでも動作します。

## 🚀 セットアップ方法

### オプション1: ローカル実行

```bash
# Python 3がインストールされている場合
python -m http.server 8000

# または Python 2の場合
python -m SimpleHTTPServer 8000
```

その後、ブラウザで `http://localhost:8000` にアクセスしてください。

## 📖 使い方

1. 「**スキャン開始**」ボタンをタップ
2. ブラウザのカメラアクセス許可画面で「許可」を選択
3. QRコードをカメラに向ける
4. 自動的に読み込まれます
5. 「📋 コピー」でコンテンツをコピー
6. 「🔗 開く」でURLを開く（URL形式の場合）

## 🐛 トラブルシューティング

### カメラが起動しない場合

1. ブラウザの設定でカメラアクセスが許可されているか確認
2. 別のアプリでカメラを使用していないか確認
3. ブラウザのキャッシュをクリアして再度試す
4. HTTPS接続を使用しているか確認（localhost以外）

### QRコードが読み込まれない場合

1. QRコードが正常か確認
2. 照明が十分か確認
3. カメラのピントが合っているか確認
4. QRコードとカメラの距離を調整
